# CS-360-Module-Eight
Overview of the Project
The objective of this project was to create a Weight Tracking application that offers the intended audience a simplified, user-friendly experience.
Which features and screens were required to fulfill user needs and provide a user-centered user interface?
I created an interactive grid/list for data entry, a data visualization dashboard, and a secure login/registration screen to assist the user. I made sure the UI remained accessible and lessened the user's cognitive load by utilizing user-centered design concepts, such as constant navigation bars and high contrast buttons.
How did you go about writing the code for your application?
I used an iterative approach to the coding process that was influenced by Agile. In order to guarantee data integrity, I concentrated on developing the backend database architecture (SQLite/Room) first, then the UI-to-Logic coupling. In order to effectively manage memory for database instances, I adopted the Singleton design; I will use this technique in future projects to guarantee scalability.
How did you verify the functionality of your code?
Unit testing for core logic and manual emulator testing were used in the testing process. This procedure is essential because it highlights "edge cases," including how the application manages screen rotations or empty data fields.
